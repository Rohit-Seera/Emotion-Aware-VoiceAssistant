# Emotion-Aware Voice Assistant — Start Here

1. Install Python 3.13.
2. Copy .env.example to .env and add your own provider credentials. Do not publish .env.
3. From the project folder, double-click START_EMOTION_AWARE_VOICE_ASSISTANT.bat.
4. Allow the launcher to prepare dependencies and start the local backend.
5. Open http://127.0.0.1:8000/api/v1/demo?visual=particles if the browser does not open automatically.

Provider-backed speech recognition, LLM responses, and speech synthesis depend on valid local credentials and provider availability. Local fallback behavior is for demonstrating the interface and must not be presented as a measured model result.
